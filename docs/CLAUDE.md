# Як підключити свого Claude до календаря Е2

Через MCP Claude може читати переписку чатів групи, де ти учасник (з моменту, коли туди додали бота), календар,
дедлайни, новини, а також транскрипти записаних пар і зустрічей. Ті, кому адмін дав право запису, можуть ще й додавати дедлайни, новини й заняття. Видаляти
через Claude нічого не можна: усі зміни видно в «Журналі змін» на сайті з твоїм ім'ям і їх можна відкотити.

## 1. Отримай ключ

Відкрий [@karazin_e2_agent_bot](https://t.me/karazin_e2_agent_bot?start=key) і натисни «Start» (або напиши йому `/key`). На сайті те саме робить кнопка «Увійти» → «Отримати ключ у Telegram». Ключ видається учасникам основних чатів групи, до яких підключений бот.
Через Claude ти бачиш переписку лише тих чатів, у яких сам є.

Ключ дає **тільки читання**. Якщо тобі треба додавати дедлайни й новини, попроси адміна: він дасть право
командою `/grant`, і перевипускати ключ не доведеться.

- Ключ **один на всі пристрої** і діє пів року: `/key` щоразу показує той самий ключ і продовжує його ще на пів року. Тож для другого ноутбука чи сайту просто напиши `/key` ще раз.
- `/revoke`: відкликати всі свої ключі.
- Якщо вийдеш з усіх чатів групи, ключ перестане працювати автоматично.

Ключ дає доступ до переписки групи. Нікому його не пересилай і видали повідомлення з ним після копіювання.

## 2. Підключи

**Claude Code:**

```sh
claude mcp add --transport http e2 https://АДРЕСА-САЙТУ/mcp --header "Authorization: Bearer e2_твій_ключ"
```

**Claude Desktop / інші клієнти з конфігом `mcpServers`** (через `mcp-remote`, потрібен Node.js):

```json
{
  "mcpServers": {
    "e2": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://АДРЕСА-САЙТУ/mcp", "--header", "Authorization: Bearer ${E2_KEY}"],
      "env": { "E2_KEY": "e2_твій_ключ" }
    }
  }
}
```

Браузерні claude.ai, ChatGPT та Gemini поки не підтримуються: їм потрібен OAuth-логін, а не ключ.

## 3. Користуйся

Приклади запитів до Claude:

- «Що обговорювали в чатах групи сьогодні? Коротко.»
- «Що писали в чаті з англійської за тиждень?»
- «Прочитай чат за останні 3 дні і знайди дедлайни, яких ще немає в календарі. Покажи список, я підтверджу.»
- «Що здавати цього тижня?»
- «Додай новину: практичне з методології 20.11 о 12:00 замість 13:40.»
- «Що казали про індивідуальний план на зустрічі 23.10? З таймкодами.»
- «Знайди в записах лекцій усе про вимоги до публікацій.»
- «Зроби конспект лекції #3 з таймкодами і збережи його.» (потрібне право запису)

Перед кожним додаванням Claude має показати, що саме додасть, і чекати твого «так».
