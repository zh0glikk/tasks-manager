# Як підключити свого Claude до календаря Е2

Через MCP Claude може читати переписку чату групи (з моменту, коли туди додали бота), календар, дедлайни
й новини, а також додавати дедлайни, новини й заняття. Видаляти через Claude нічого не можна: усі зміни
видно в «Журналі змін» на сайті з твоїм ім'ям і їх можна відкотити.

## 1. Отримай ключ

Напиши боту групи в особисті `/key`. Ключ видається тільки учасникам чату групи.

- `/key read`: ключ тільки для читання.
- `/key` ще раз: новий ключ, старий перестає працювати.
- `/revoke`: відкликати ключ.
- Якщо вийдеш з групи, ключ перестане працювати автоматично.

Ключ дає доступ до переписки групи. Нікому його не пересилай і видали повідомлення з ним після копіювання.

## 2. Підключи

**Claude Code:**

```sh
claude mcp add --transport http e2 https://АДРЕСА-САЙТУ/mcp --header "Authorization: Bearer e2_твій_ключ"
```

**Claude Desktop / інші клієнти з конфігом `mcpServers`** (через `mcp-remote`, потрібен Node.js):

```json
{
  "mcpServers": {
    "e2": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://АДРЕСА-САЙТУ/mcp", "--header", "Authorization: Bearer ${E2_KEY}"],
      "env": { "E2_KEY": "e2_твій_ключ" }
    }
  }
}
```

Браузерні claude.ai, ChatGPT та Gemini поки не підтримуються: їм потрібен OAuth-логін, а не ключ.

## 3. Користуйся

Приклади запитів до Claude:

- «Що обговорювали в чаті групи сьогодні? Коротко.»
- «Прочитай чат за останні 3 дні і знайди дедлайни, яких ще немає в календарі. Покажи список, я підтверджу.»
- «Що здавати цього тижня?»
- «Додай новину: практичне з методології 20.11 о 12:00 замість 13:40.»

Перед кожним додаванням Claude має показати, що саме додасть, і чекати твого «так».
